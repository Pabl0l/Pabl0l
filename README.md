## Sobre mí

Técnico en mantenimiento de sistemas informáticos, egresado de la Institución Universitaria de Barranquilla (2024–2026). Experiencia en hardware, redes Cisco y desarrollo de software.

Construyo herramientas que eliminan trabajo repetitivo: automatizaciones, utilidades y apps que resuelven problemas concretos y que cualquiera puede ejecutar. Actualmente trabajo en **BMO**, una suite de automatización para PYMES colombianas, y uso Claude Code y OpenCode como parte del flujo diario.
